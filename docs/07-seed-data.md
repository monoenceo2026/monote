## 7.3 生成企業（123社）の作り方

**検索デモの数字を成立させるために、逆算して生成している。**

| 目標 | 値 | 意味 |
|---|---|---|
| `targetSUS` | 48社 | `ステンレス × 板金・プレス × 1個から（試作）` にヒットする社数 |
| `targetFast` | 24社 | さらに `短納期（7日以内）` も満たす社数 |

これにより、`/search` の既定状態（4条件）で **24社**、
納期条件を外すと **48社** ——構想デザインの「24社 ⇄ 48社」がそのまま再現される。

その他の属性:
- 会社名 = 接頭辞22種 × 接尾辞10種（重複回避）
- 55% が関西、45% が関東。都道府県ごとに実在の市区を割り当て
- `verified` は60%、`ISO9001` は55%、`ISO14001` は15%
- 精度は 0.01 / 0.05 / 0.1mm を 30% / 30% / 40% で配分（0.01mm には `precision` 条件を付与）
- `completeness` は 30〜89%、`updated_at` は直近90日にばらつかせる

## 7.8 動作確認シナリオ

### A. 探す側の一周（未ログインでも可）

1. `/` → 「企業を探す」
2. `/search` — 既定4条件で **24社**。サイドバーの件数がすべて実数
3. 緩和サジェスト「納期条件を外すと **48社**」をクリック → 48社になる
4. 企業カードから `/companies/marumaru-seisakusho` へ（`click` イベントが記録される）
5. 「対応が難しい条件」まで読んだ上で「比較に追加」
6. 3社を比較リストに入れて `/my/compare` — 優位セルがサーバー計算でハイライトされる
7. メモを書く → リロードしても残る（`compares.memo`）
8. 「3社にまとめて相談」→ `/inquiry/new?companies=...&source=compare`
9. 必須項目（加工・材質・数量・会社名・担当者名・メール）を埋めて送信 → 完了画面

### B. つくる側で成果を確認

10. `/login` → 「製作所でログイン」→ `/admin`
11. 受信箱に **9. で送った相談が届いている**（未対応3件に増える）
12. 「返信する」→ ステータスが変わる
13. 条件別テーブルで「精密板金 × 医療機器」に改善サジェストが出ている
14. `/admin/articles/new` で記事を書く → 自動保存（下書き）→ 公開
15. `/articles` と `/search`（記事タブ）に**公開した記事が出る**。条件を付ければ条件検索でも拾われる

### C. 新規企業として登録

16. ログアウトして `/signup`
17. 会社名と加工・材質チップを入れる → 充足度メーターが動く
18. ロット下限 1、標準納期 5〜7日 などを入れて送信
19. `/search` で **登録した会社が実際にヒットする**（`lot:1個から`・`delivery:短納期` が自動付与されるため）
