# MONOTE ドキュメント

MONOTE（モノテ）は、株式会社モノエンが構想する **製造業特化型の情報発信・企業検索プラットフォーム** です。
このリポジトリは、その事業構想を実際に触れる形にしたβ版（Next.js + SQLite）の実装を含みます。

このドキュメント群は、
「PDF の事業構想草案（`MONOTE 初期構想草案 2026.07`）」と
「リポジトリ内の実装」の両方を突き合わせて作成した、MONOTE の詳細資料です。

## 30秒でわかる MONOTE

- **課題**: 製造業の技術情報は「探せず、発信も続かない」。発信側・探索側・運営側の三者に構造的な摩擦がある。
- **解**: 記事数を増やすことではなく、**技術情報が“選定・比較・相談”に使われる状態**をつくる。
- **手段**: 記事と企業プロフィールの両方に、加工・材質・ロット・納期・認証・エリア・精度という
  **製造業の条件（conditions）を構造化して持たせ、横断検索できるようにする**。
- **収益**: 登録・投稿・基本検索掲載は無料。**優先表示／レコメンド**と**運用代行**で収益化する。
- **成果指標**: 閲覧数ではなく、**専門検索での表示・保存・比較・相談**という行動を計測する。
