# MONOTE

製造業特化型の情報発信・企業検索プラットフォーム。
加工方法・材質・ロット・精度・認証などの条件で、技術記事と企業情報をまとめて検索できます。

Figmaデザイン: https://www.figma.com/design/gnam2ewPe2dZ2ivBazOgBq/MONOTE

## 技術構成

- **Next.js 15**（App Router / TypeScript / Server Components + Server Actions）
- **SQLite**（better-sqlite3）— 初回起動時に `data/monote.db` を自動作成し、デモ用データをシード
  - 掲載企業128社・技術記事342本・検索条件タクソノミー・行動イベント（表示/クリック/保存/相談）
- スタイルはプレーンCSS（`css/`）。デザイントークンは `css/base.css`

## 起動

```bash
npm install
npm run dev    # http://localhost:3000
```

本番ビルド:

```bash
npm run build && npm start
```

DBを作り直す場合は `data/monote.db*` を削除して再起動（自動で再シードされます）。

## デモアカウント（/login からワンクリック）

| ロール | 名前 | 試せること |
|---|---|---|
| 探す側（発注） | 田中 様 | 検索、保存・比較（シード済み3社+メモ）、相談の送信、相談履歴 |
| つくる側（掲載企業） | 株式会社○○製作所 | ダッシュボード（実イベント集計）、相談の受信箱、記事の投稿・公開、対応条件の編集 |

## 主なルート

| ルート | 内容 |
|---|---|
| `/` | TOP。ヒーローはモノエンロゴシンボルのモーフィングモーション |
| `/search` | 条件検索。ファセット件数・緩和サジェスト・比較バーすべて実データ |
| `/companies/[slug]` | 企業詳細。閲覧イベントを記録（ダッシュボードに反映） |
| `/articles` `/articles/[slug]` | 技術記事。条件チップから同条件の企業検索へ接続 |
| `/my/compare` | 保存・比較。優位セルはサーバーで実計算、メモはDB保存 |
| `/inquiry/new` | 相談・見積依頼。送信すると相手企業の受信箱に届く |
| `/signup` | 企業登録（対応条件）。登録した会社は実際に検索でヒット |
| `/admin` | 企業管理ダッシュボード。KPI・検索条件別成果・受信箱（返信/対応不可） |
| `/admin/articles/new` | 記事エディタ。自動保存（下書き）と公開 |

## データ・計測の流れ

検索結果の表示は `impression`、検索経由の企業ページ閲覧は `click`、直接閲覧は `view`、
保存・相談もイベントとして記録され、`/admin` のダッシュボードはこれらの30日集計です。
シードデータはFigmaデザインに描かれた数値（検索24社⇄納期を外すと48社、
インプレッション1,284回、受信箱 未対応2件など）が実クエリで再現されるよう調整しています。
